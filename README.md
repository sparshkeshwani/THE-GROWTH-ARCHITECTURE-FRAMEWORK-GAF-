## ⚡ Dual-Path Accessibility

GAF is built for both non-technical growth executives and technical AI engineers. Choose your path below:

### 👔 For Non-Technical Marketers (Instant Plug & Play)

You do **not** need to touch terminal commands or write a single line of code to leverage GAF.

1. **Download the Core Framework**:
   👉 [**Download `assets/gaf-core.md` Directly**](assets/gaf-core.md) *(Right-click > Save Link As... or click and copy raw text).*
2. **Open Your AI Assistant**:
   Navigate to [ChatGPT](https://chatgpt.com), [Claude](https://claude.ai), [Google Gemini](https://gemini.google.com), or [Perplexity](https://perplexity.ai).
3. **Inject as System Instruction or Project Knowledge**:
   - **Claude Projects**: Paste the contents of `gaf-core.md` into Project Knowledge.
   - **Custom GPTs**: Paste `gaf-core.md` into the GPT Instructions field.
   - **Direct Chat**: Paste `gaf-core.md` once at the beginning of a fresh chat session.
4. **Fire a Directive**:
   Copy and paste any Directive from Section 4 of `gaf-core.md`, for example:
   ```text
   [TASK DIRECTIVE]: Execute Module 1.4 (Pricing Architecture & Packaging Design) for [Your Product]. 
   Goal: Structure tier packaging, value-metrics, and feature-gating thresholds for SaaS growth.
   ```

### 💻 For Nerds & Engineers (CLI, cURL & Programmatic Code)

Integrate GAF directly into your autonomous agents, Cursor IDE rules, LangChain workflows, or CI/CD pipelines.

#### 1. Instant cURL One-Liner

Fetch the raw framework markdown directly into your current directory or AI system prompt:

```bash
# Download GAF Core directly via cURL
curl -sSL https://raw.githubusercontent.com/sparshkeshwani/growth-architecture-framework/main/assets/gaf-core.md -o gaf-core.md

# Or inspect the raw framework directly in terminal
curl -sSL https://raw.githubusercontent.com/sparshkeshwani/growth-architecture-framework/main/assets/gaf-core.md | less
```

#### 2. Python Integration (OpenAI, Anthropic & Google GenAI)

Load GAF as your autonomous CMO system prompt with standard Python SDKs:

```python
import os
from pathlib import Path
from google import genai
from google.genai import types

# 1. Load the GAF Core framework
gaf_system_prompt = Path("assets/gaf-core.md").read_text(encoding="utf-8")

# 2. Initialize Gemini Client (or OpenAI / Anthropic)
client = genai.Client(api_key=os.environ.get("GEMINI_API_KEY"))

# 3. Execute a GAF Task Directive
response = client.models.generate_content(
    model="gemini-2.5-flash",
    config=types.GenerateContentConfig(
        system_instruction=gaf_system_prompt,
        temperature=0.2, # Low temperature for analytical precision
    ),
    contents="""
    [TASK DIRECTIVE]: Execute Module 3.3 (Generative Engine Optimization - GEO) for AcmeCloud AI.
    Objective: Build a brand citation matrix and direct-answer content optimization plan for Perplexity and ChatGPT Search.
    Product: AcmeCloud (Serverless vector database)
    ICP: Staff AI Engineers and CTOs
    KPI: Top 3 recommendation ranking in AI answer engines
    """
)

print(response.text)
```

#### 3. Node.js / TypeScript Integration

```typescript
import * as fs from 'fs';
import * as path from 'path';
import { GoogleGenAI } from '@google/genai';

async function runGAFTask() {
  const gafCore = fs.readFileSync(path.resolve('./assets/gaf-core.md'), 'utf-8');
  const ai = new GoogleGenAI({ apiKey: process.env.GEMINI_API_KEY });

  const response = await ai.models.generateContent({
    model: 'gemini-2.5-flash',
    contents: `
      SYSTEM CONTEXT:
      ${gafCore}

      EXECUTION REQUEST:
      [TASK DIRECTIVE]: Execute Module 5.3 (Product-Led Growth Mechanics) for DataPulse.
      Scope: Define PQL scoring criteria, feature activation triggers, and in-app upgrade prompt scripts.
    `,
  });

  console.log(response.text);
}

runGAFTask();
```

## 🏛️ The 9 Core Task Modules

GAF breaks down the entire Integrated Marketing Communications ecosystem into 9 modular, self-contained disciplines covering 28+ mission-critical capabilities:

| Module | Title | Core Strategic Focus & Deliverables |
| :--- | :--- | :--- |
| **01** | **Audience, Brand & Positioning** | Persona synthesis, UVP battlecards, objection handling, pricing architecture, monetization models, and crisis PR incident playbooks. |
| **02** | **Lead Gen & Acquisition Funnels** | High-converting lead magnets, gated content architecture, automated email drip series (welcome, activation, re-engagement), and Tier 1/2/3 ABM at scale. |
| **03** | **Content Strategy, SEO & Answer Engines** | Topic clusters, search intent keyword trees, technical on-page SEO, **Generative Engine Optimization (GEO)** for Perplexity/ChatGPT/Gemini, and content repurposing engines. |
| **04** | **Paid Media & Performance Marketing** | Multi-channel PPC/Social campaign structures (Google, LinkedIn, Meta), budget allocation matrices, and multi-variant creative testing hooks to minimize CAC. |
| **05** | **Lifecycle Marketing, PLG & Retention** | Onboarding TTV acceleration, churn reduction playbooks, Product-Led Growth (PQL scoring, freemium loops), and omnichannel cross-channel state-machine routing. |
| **06** | **Go-to-Market (GTM), Sales Enablement** | Full-scale launch playbooks, enterprise sales battlecards, buyer deck outlines, co-marketing partnership engines, and virtual/field event architectures. |
| **07** | **Ecosystem, Partnerships & Advocacy** | Programmatic influencer/creator onboarding, affiliate commission tiers, affiliate fraud detection SOPs, and community ambassador programs. |
| **08** | **Global Strategy, Localization & Compliance** | Multi-regional cultural adaptation, privacy governance (GDPR, CCPA, DPDP), cookie consent architecture, and synthetic media/trademark brand safety guardrails. |
| **09** | **Advanced Analytics, Operations & AI Architecture** | Multi-touch attribution (MTA), marketing mix modeling (MMM), LTV:CAC cohort math, MarTech stack routing, **agentic multi-agent orchestration**, and model fine-tuning pipelines. |
