## 🏛️ Architectural Manifesto by Sparsh Keshwani

> *"Modern marketing is fractured. Companies subscribe to dozens of point solutions, employ disjointed agencies, and rely on superficial AI prompts that produce generic marketing fluff. **GAF was architected to be the definitive operating system for growth.** It eliminates prompt degradation by embedding deterministic variables, multi-stage audits, and quantifiable business deliverables into every model interaction."*  
> — **Sparsh Keshwani**

Traditional AI prompts fail in enterprise environments for three specific reasons:
1. **Context Blindness:** Models do not understand unit economics (CAC, LTV, ARR payback), brand governance, or jurisdictional privacy laws (GDPR, CCPA, DPDP).
2. **Unstructured Output Drift:** Without a deterministic framework, outputs fluctuate between vague theoretical advice and low-converting generic copy.
3. **Siloed Execution:** Most prompts handle isolated tasks without considering the upstream positioning or downstream attribution mechanics.

**The Growth Architecture Framework by Sparsh Keshwani permanently resolves this** by supplying an all-in-one Integrated Marketing Communications (IMC) backbone that works across any modern foundation model (Claude 3.7, GPT-4o, Gemini 2.0, Perplexity, Grok, and Cursor).

## 🔄 Universal 4-Step Execution Workflow

Every module inside **Sparsh Keshwani's GAF** executes via a standardized, strict 4-step pipeline:

```
[Step 1: Context & Audit]
    │  Audits ICP parameters, positioning battleground, target geography, 
    │  economic benchmarks, and multi-agent pipeline constraints.
    ▼
[Step 2: Strategy & Outline]
    │  Drafts structural outlines, decision logic, mathematical frameworks, 
    │  or state-machine routing rules prior to content synthesis.
    ▼
[Step 3: Asset Generation]
    │  Synthesizes complete, production-ready deliverables—including full copy, 
    │  SOP documentation, pricing algorithms, or code/configuration blocks.
    ▼
[Step 4: Optimization & Formatting]
    │  Refines copy for platform-specific conversion heuristics, regulatory compliance 
    │  (GDPR/CCPA/FTC), brand-safety filters, and agentic JSON handoffs.
```

## 🚀 Dual-Path Accessibility Guide

Sparsh Keshwani engineered GAF to ensure equal accessibility for non-technical marketing executives and senior AI engineers.

### 1. For Non-Technical Marketers (Instant Plug & Play)

Zero code required. Get started in less than 60 seconds:

1. **Download the Raw Framework:**
   - Click 👉 [**`assets/gaf-core.md`**](assets/gaf-core.md) and save the file to your machine.
2. **Select Your AI Platform:**
   - **ChatGPT / Custom GPTs:** Paste the contents of `gaf-core.md` into your Custom GPT *Instructions* or into ChatGPT's *Custom Instructions*.
   - **Claude.ai Projects:** Create a new project, upload `gaf-core.md` under *Project Knowledge*, and set instructions: *"Execute all directives strictly adhering to Sparsh Keshwani's GAF."*
   - **Google Gemini Gems:** Create a custom Gem titled **"GAF CMO Engine"** and paste `gaf-core.md` into the system prompt.
   - **Perplexity AI Collections:** Create a new Collection named **"GAF Marketing Ops"** with `gaf-core.md` as the collection prompt for real-time search-grounded marketing workflows.
3. **Deploy Any Task Directive:**
   Copy and paste ready-to-run directives directly from Section 4 of `gaf-core.md`:

```text
[TASK DIRECTIVE]: Execute Module 1.4 (Pricing Architecture & Packaging Design) for [PRODUCT NAME]. 
Goal: Structure tier packaging, value-metrics, and feature-gating thresholds for SaaS growth.
```

#### Python Implementation (`examples/python_gemini.py`)
Load GAF as your system instruction using the Google GenAI, OpenAI, or Anthropic SDK:

```python
"""
The Growth Architecture Framework (GAF) by Sparsh Keshwani
Autonomous CMO Python Implementation
"""

import os
from pathlib import Path
from google import genai
from google.genai import types

# 1. Load GAF Core authored by Sparsh Keshwani
gaf_system_prompt = Path("assets/gaf-core.md").read_text(encoding="utf-8")

# 2. Initialize frontier AI client
client = genai.Client(api_key=os.environ["GEMINI_API_KEY"])

# 3. Execute GAF Directive with deterministic low temperature
response = client.models.generate_content(
    model="gemini-2.5-flash",
    config=types.GenerateContentConfig(
        system_instruction=gaf_system_prompt,
        temperature=0.2, # Low temperature ensures strict adherence to GAF
    ),
    contents="""
    [SYSTEM CONTEXT & VARIABLES]
    Product: VectorFlow AI (Serverless Vector Search Engine)
    ICP: Staff AI Infrastructure Engineers & CTOs (Series A-C)
    Primary Goal/KPI: Achieve $1.5M ARR with blended CAC under $800
    Brand Tone: Authoritative, deeply technical, developer-first
    Channels: Generative Engine Optimization (GEO), LinkedIn, In-App CLI
    
    [TASK DIRECTIVE]
    Execute Module 3.3 (Generative Engine Optimization - GEO).
    Objective: Build an authoritative brand citation matrix and direct-answer content plan for Perplexity, ChatGPT Search, and Gemini.
    """
)

print(response.text)
```

#### TypeScript / Node.js Implementation (`examples/node_script.ts`)
```typescript
import * as fs from 'fs';
import * as path from 'path';
import { GoogleGenAI } from '@google/genai';

async function runGafCmo() {
  const gafCore = fs.readFileSync(path.resolve('./assets/gaf-core.md'), 'utf-8');
  const ai = new GoogleGenAI({ apiKey: process.env.GEMINI_API_KEY! });

  const response = await ai.models.generateContent({
    model: 'gemini-2.5-flash',
    contents: `
      [FRAMEWORK SYSTEM INSTRUCTIONS BY SPARSH KESHWANI]
      ${gafCore}

      [EXECUTION DIRECTIVE]
      [TASK DIRECTIVE]: Execute Module 5.3 (Product-Led Growth Mechanics) for AcmeCloud.
      Scope: Define PQL criteria, usage triggers, and in-app upgrade scripts.
    `,
  });

  console.log(response.text);
}

runGafCmo();
```
